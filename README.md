# scSimu: Single-Cell SIMUlation

scSimu is an R package used to simulate scRNA count data from real data.

## Quick Start
* Install `scSimu` using `devtools::install_github("xs222/scSimu")`
* A detailed tutorial can be found in [Tutorial.html][tutorial]

[tutorial]: https://github.com/xs222/scSimu/blob/master/vignettes/Tutorial.html

## Reference
Shan, X., Zhao, H.: A Unified Framework for Selecting and Evaluating Cell-Type-Specific Gene Co-expressions in Single-Cell Data.
